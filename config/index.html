⌨️ Command cheat sheet

Sites

./vhost.sh --add --letsencrypt Create a site and issue a Let's Encrypt certificate
./vhost.sh --list List all sites
./vhost.sh --delete Delete a site, optionally removing its directory

Upgrade & backup

./upgrade.sh Interactive upgrade for web server / database / PHP
./backup_setup.sh Configure scheduled backups: local / remote / cloud
./backup.sh Run a backup right now

Extensions & accounts

./addons.sh Install PHP extensions and addons
./pureftpd_vhost.sh Manage FTP accounts: create / list / delete
./reset_db_root_password.sh Reset the database root password

Handle with care

./uninstall.sh --all Remove all installed components, keep data directories
./uninstall.sh --purge Remove components and clean up Lemon's own config

Common paths

Site root__WWWROOT__
Web config__WEB_CONF__
PHP config__PHP_ETC__
DB data__DB_DATA__
Logs__LOGS__
Install log__INSTALL_LOG__

⚠️ Security notes

  • Database port listens on all interfaces by default. Change bind-address or enable a firewall if you don't need remote access.
  • Cache panels (ocp.php / apc.php) are not deployed by default. Deploy manually with access control if needed.
